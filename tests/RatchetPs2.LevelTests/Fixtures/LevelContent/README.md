Synthetic native archives for level-content conversion regressions. These small fixtures contain one or two instances, native gameplay/PVar tables, texture patterns, and sky/collision payloads. They were captured from the existing Forge protocol test fixture builders; Forge tests link the same files so editor transaction tests and SDK binary tests use identical inputs. dl-empty-fixups.wad differs by empty aligned DL fixup padding. These are test inputs, not extracted retail level archives.

`rc1-oversized-tie.bin` is a synthetic RC1 class with three LODs of 150 packets each. The packets share one 64-vertex strip payload to keep the fixture small; its per-LOD lighting cache exceeds the native UYA group limit. It exercises multipart model conversion and Forge replacement/undo/baking without retail model data.
